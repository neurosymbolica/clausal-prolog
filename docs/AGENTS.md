# docs/ — the MkDocs user site (clausal.pl)

The user-facing documentation, built by MkDocs (Material theme) from
[`../mkdocs.yml`](../mkdocs.yml) at the repo root. Published on push to `main`
to GitHub Pages ([`../.github/workflows/docs.yml`](../.github/workflows/docs.yml))
and GitLab Pages (the `pages` job in `../.gitlab-ci.yml`); the domain is
`clausal.pl` (`../CNAME`). Code blocks in the top-level pages are **tested**
(see below), so a docs edit can fail the test suite.

Examples are **Clausal Prolog** (`.clausal`, ISO syntax) in ```` ```clausal ````
fences (moved from seam syntax on 2026-10-17). Write new examples that way.
Use a ```` ```seam ```` fence only where the seam itself is the subject: the
seam pages (`syntax.md`, `python_integration.md`, `for_python_programmers.md`),
a block that calls Python (`++expr`, `async def`), or a feature that only the
seam can spell. Say in the prose that such a block is seam. Keep the library
names as they are: `.clausal` sees `in_/2`, `zip_/3` and the rest. Seam's
bare `==` is a CLP(ℤ) constraint; in `.clausal` write `#=` for arithmetic,
`==` for a test of a bound value, and `=` to bind. Optional packages keep
their own docs under `../packages/clausal-*/docs/`.

## Tested code blocks

| Mechanism | Where |
|---|---|
| Every ```` ```clausal ```` block (loaded as `.clausal`) and ```` ```seam ```` block (loaded as `.seam`) in `docs/*.md` is collected by the root [`../conftest.py`](../conftest.py) (`DocMdFile`): its `test/1` clauses run as pytest items, otherwise it is compile-checked (`docs/x.md::L52 [compile]`). Indented blocks inside admonitions count | `python -m pytest docs` |
| Every inline ```` ```clausal ```` block loads and all its tests pass (stricter than the seam check, which trusts a block that contains a test) | [`../tests/test_doc_clausal_blocks.py`](../tests/test_doc_clausal_blocks.py) |
| No `# skip` blocks (ratchet at 0); a seam block must compile, contain a test, or be a `--8<--` reference | [`../tests/test_doc_snippet_coverage.py`](../tests/test_doc_snippet_coverage.py) |
| Every snippet reference (scissors line + quoted `file:section`) resolves; referenced `.seam` fixtures contain tests (`.clausal` fixtures run as pytest items anyway) | [`../tests/test_doc_snippet_integrity.py`](../tests/test_doc_snippet_integrity.py) |
| Selected ```` ```python ```` blocks run verbatim in a subprocess (some build modules from ```` ```clausal ```` or ```` ```prolog ```` blocks) | [`../tests/test_doc_python_blocks.py`](../tests/test_doc_python_blocks.py) |
| A failing doc block reports a goal-level diagnosis | [`../tests/test_doc_block_diagnostics.py`](../tests/test_doc_block_diagnostics.py) |

Shared check logic: [`../clausal/tools/doc_snippet_check.py`](../clausal/tools/doc_snippet_check.py).
Snippets (`pymdownx.snippets`) live in `../tests/fixtures/docs/`:
`<page>_sigs.txt` (display-only signatures, shown in a ```` ```text ```` fence),
`<page>_sig_tests.clausal` (their companion tests), `<page>_examples.clausal`
(executable examples with `test/1`). Every `.clausal` fixture there is also a
pytest file. A few `.seam` fixtures remain for seam-only features. A fixture
marks a section with scissors comments (`% --8<--` in `.clausal`, `# --8<--` in
`.seam`, plus
`[start:name]` ... `[end:name]`); a page includes it with a block whose only
line is the scissors marker followed by the quoted path
`"tests/fixtures/docs/<file>:<name>"` (copy one from `lists.md`). Do not write
that include line literally anywhere else in `docs/*.md` (this file included):
the integrity test and `mkdocs build` (`check_paths: true`) would try to resolve
it. Pattern write-up:
[`../implementation_plans/docs/DOC_SNIPPET_TESTING.md`](../implementation_plans/docs/DOC_SNIPPET_TESTING.md).

## Gotchas

- ```` ```clausal ```` and ```` ```seam ```` are the fences that run.
  ```` ```prolog ```` is not run by the doctests, but `pl_parity` loads every
  ```` ```prolog ```` block under both `.pl` front ends and pins the result by
  `page#Lline` in `../tests/fixtures/pl_parity_native.json`. Moving or
  re-fencing one changes that fixture, and the summary block in
  `../implementation_plans/native-iso-reader-step2-2026-09-29/parity-2026-10-12.md`.
- `test_doc_snippet_coverage.py`'s `_KNOWN_UNCOMPILABLE` (allowlist by fence
  line) and `test_doc_clausal_blocks.py`'s `_KNOWN_DISPLAY_ONLY` are empty: keep
  them that way. Make a fragment a whole program, or show it as
  ```` ```text ````.
- The snippet checks scan only top-level `docs/*.md`; the root `conftest.py`
  keeps `pytest` off `superpowers/` and `design-records/` (history whose seam
  blocks predate today's syntax).
- Pre-flip text (mostly under `superpowers/`) may say `.clausal` meaning seam
  source.
- Local preview: `python docs/serve-docs.py` (rebuilds, serves on :8080).
