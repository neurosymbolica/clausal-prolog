● A04 is done and committed (2af2b487). This subsystem turned out to be the
  richest audit yet: 10 confirmed correctness findings + 1 design finding, all
  reproduced with executed pytest — the test file is green per-file (24 passed,
  20 xfailed, every xfail genuinely failing).

  The headline findings (tabling is much more broken than its 97 passing in-tree
  tests suggest):

  - A04-F001 — SLG completion is architecturally broken. The completion phase
  resumes suspended consumers whose parent generators are already dead, and its
  interception freezes the consumer's call args (necessarily a duplicate)
  instead of running the clause continuation — so completion can never add an
  answer. An idiomatic facts-first program with two recursive clauses returns
  [1,2,3] instead of [1,2,3,4,5]; recursive-clause-first returns [1]; mutual
  recursion caches an inner table as complete-with-zero-answers. In-tree
  fixtures pass only because one-recursive-clause/facts-first reaches fixpoint
  during the live phase. Filed as an Opus investigate (needs SCC-aware
  completion).
  - A04-F002/F003 — negation is order- and mode-dependent. not tp(1,2) with fact
  tp(1,2) succeeds if tp was never queried (the no-entry path "treats as no
  answers" instead of evaluating the subgoal), and a complete tp(_,_) table
  holding the answer is ignored (exact-variant lookup). The docs' asymmetric-win
  example gives win("b")=1-answer-undefined if queried first — cached wrong
  forever — and var-mode yields {a,b} where ground mode yields {a}.
  - A04-F005 — tabled answers containing lists crash (TypeError: unhashable),
  likewise dicts/sets/term instances — tabling only works for scalar answers
  today.
  - A04-F007/F008 — once() over a tabled goal poisons the table ("evaluating"
  forever → later queries silently partial, plus a spurious unbound answer
  because all four root drivers misread (None, _TABLING_SUSPEND) as a solution).
  - A04-F009 — the C driver swallows any user RuntimeError from ++ escapes:
  call/solve/once silently fail while solutions() raises — entry points
  disagree.
  - Plus: query_wfs truth annotation is a hardcoded-True stub (F004), cross-type
  answer conflation 1≡True≡1.0 making tabled/untabled solution sets diverge
  (F006, cites parked A01-D001/A02-D002), the when/2-disjunction fired-flag
  surviving backtracking (F010), and freeze/2 committing to the frozen goal's
  first solution (F011, design).

  Clean bills of health: deep recursion (30k tail calls), the _tabling_core
  C-stack depth guards, refcount/alloc stability, C≡Py parity for
  list-unification (220-cell differential grid) and key/deref-walk, the
