# clausal/modules/ — Python-backed predicate modules

Python modules whose public attributes are predicate adapters (objects with
`_get_dispatch`, usually `ModulePredicate`) or values (units, currencies,
numbers). A seam file imports them directly (`-import_from(py.json, [parse])`,
`-import_from(graphs, [...])`); a `.pl` file can `use_module(py/json, [...])`;
a Clausal Prolog (`.clausal`) file may **not** name them and goes through the
generated `library(...)` facades in [../library/](../library/AGENTS.md)
instead. Extension distributions (`packages/clausal-*`) add more files to this
package and to `py/` via namespace-path extension in the `__init__.py` files.

Up: [../AGENTS.md](../AGENTS.md)

## Map

| Path | What it is | Facade |
|---|---|---|
| `py/` | Wrappers over Python libraries (json, datetime, re, sqlite, http, ...) and the shared adapter base. See [py/AGENTS.md](py/AGENTS.md). | `library(<name>)` or `library(py_<name>)` |
| `units.py` | SI units and dimensional analysis: `_UnitsPredicate` units (`metre`, `newton`, ...), prefixes, conversion predicates. Importing it builds 84 `Quantity` constants and turns on the CLP units side channel. | `library(units)` |
| `imperial.py` | Imperial/non-SI units as plain `Quantity` values in SI base units. | `library(imperial)` |
| `_unit_registry.py`, `_ratio_data.py` | Data-only unit tables. Must never import `units.py` (see gotchas). | none |
| `currency.py` | Money constructors, rounding, formatting, currency metadata accessors. | `library(currency)` |
| `countries/` | One module per jurisdiction defining its currencies (`thailand.baht`, `european_union.euro`), `_currency.py` (the currency-as-units-base-dimension factory) and `_data.py` (ISO 4217 table). | `library(countries/<j>)` |
| `pure_random.py` | The pure, state-threaded random library: state `rng(Seed, N)`, every draw a relation `S0 -> S` (`rng_seed/2`, `random/3`, `random_between/5`, `random_member/4`, `random_permutation/4`, `random_sample/5`). Reproducibility guarantee and golden values: its docstring and `tests/test_pure_random.py`. Supersedes the deprecated `py/random.py`. | `library(pure_random)` |
| `graphs.py` | Graph predicates over edge lists (paths, cycles, connectivity, MST, ...), `_GraphPredicate` adapters. | `library(graphs)` |
| `reflection.py` | Match reified Clausal source from Clausal (`reified_clause`, `clause_body`, `goal_functor`, ...). | `library(reflection)` |
| `prolog.py` | Private reference implementations of ISO `//`, `mod`, `rem`. No public predicates. | none |

## Where to start

- Add or change a Python-library wrapper: [py/AGENTS.md](py/AGENTS.md).
- Add a domain module at this level: define `ModulePredicate` (or subclass) objects as public module attributes; `clausal.logic.solve.module_signatures` discovers predicates and arities from them. Then regenerate facades: `python -m clausal.tools.gen_library_facades`.
- Change currencies: edit `scripts/gen_currencies.py` and run it (needs `babel`); it rewrites `countries/_data.py` and every jurisdiction module. Then regenerate facades.
- How bare names (`date_time`, `regex`, a jurisdiction like `thailand`) map to `clausal.modules.*`: `_IMPORT_ALIASES` and `_resolve_import_path` in `clausal/templating/term_rewriting.py`. `py.X` imports are redirected by `ModulesFinder` in `clausal/import_hook.py`.
- Tests: `tests/test_<name>_module.py`, `tests/test_units*.py`, `tests/test_currency*.py`, `tests/test_reflection*.py`, `tests/test_clausal_modules.py`.

## Gotchas

- `countries/*.py` and `countries/_data.py` are GENERATED by `scripts/gen_currencies.py` ("Edit scripts/gen_currencies.py, not this").
- `_unit_registry.py` and `_ratio_data.py` are read on every compile; importing `units.py` from them would turn on the units side channel for every CLP program (`clausal/logic/_units_flag.py` promises "a program that imports no unit module pays nothing").
- `units.py` and `countries/_data.py` are in the bytecode-cache fingerprint (`_COMPILATION_FILES`, `clausal/import_hook.py`): editing them invalidates cached compiled code.
- `py/units.py` and `py/imperial.py` are star-import shims of the same-named modules here; they share one facade.
- Any change to a module's public predicates or values changes its facade: run `python -m clausal.tools.gen_library_facades --check` (a test enforces it).
