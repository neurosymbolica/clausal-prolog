# Examples

Each program is here twice:

- `<name>.clausal` is **Clausal Prolog**, the public surface: ISO syntax,
  no cut. Start with these.
- `<name>.seam` is the same program in the seam, the Python-syntax
  surface used where Prolog meets Python.

Every file carries its own `test/1` clauses. Run them with:

```bash
clausal --test nqueens.clausal
```

More: https://clausal.pl/examples/
