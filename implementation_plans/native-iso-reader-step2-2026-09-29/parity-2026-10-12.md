# Translator-vs-native parity, measured 2026-10-12

Slice 8.1 as re-planned 2026-10-12 (plan §4, Slice 8). Tool:
`python -m clausal.tools.pl_parity` (`clausal/tools/pl_parity.py`). Gate:
`tests/test_pl_parity.py`, which pins the list below in
`tests/fixtures/pl_parity_known.json`. Base: branch
`feat/iso-reader-slice7-2026-10-12` off main `7c0379db`.

## Method

* **Population.** Every tracked `.pl` file (`git ls-files '*.pl'`), plus each
  ```` ```prolog ````/```` ```pl ```` block of `docs/*.md`, written to a temp
  directory outside the tree. `clausal/library` and `clausal/examples` hold no
  `.pl` file today (both are `.seam`), so those populations are empty.
* **Two children per file**, one per front end, each with
  `CLAUSAL_PL_FRONTEND` set and its own empty `PYTHONPYCACHEPREFIX`. The child
  reports which loader ran, and the parent refuses a result from the wrong one.
  The file's directory, and the directory above each enclosing package, go on
  `sys.path`.
* **Compared:** load or refusal; the `test/1` and `test(Name, fail)` verdicts
  by name; for a file without tests, the all-answers of each predicate it
  defines with arity <= 3, called with fresh variables. Each call is capped at
  200 answers and 5 s. Answers are `term_writeq` text with local variable
  names.
* **Oracle.** For each difference: Scryer core
  (`/workspace/scryer-prolog`), then Trealla (`/workspace/trealla-prolog/tpl`).
  For a load difference, does the system consult the file without an error? A
  warning, such as a singleton, does not count. For a test difference, the
  verdict of `test(Name)`, or of `\+ test(Name, fail)`, through the file's
  module. For an answer difference, a failure-driven `writeq` loop.
  Comparison ignores spacing and variable names. It also prints char lists
  and one-character atoms the same way: the engine prints `"ab"` as Scryer's
  toplevel does, but `writeq/1` in a `-g` goal prints `[a,b]`. Files that end
  in `:- end_module/1` get the engine's own oracle prelude. The oracle's
  verdict is evidence. The class each difference gets is set in the fixture.
* **Fail closed.** The tool prints `N files read, M compared`. It exits 2 when
  M is 0. A crashed or timed-out child counts as a difference of kind `crash`,
  and that file is not counted as compared.

## Result

**98 files read, 98 compared** (docs 56, iso_l3 10, tests 22, plans 6, tools
4).

| translator \ native | loads | refused |
|---|---|---|
| **loads** | 51 | 1 |
| **refused** | 29 | 17 |

**40 differences: (a) 32, (b) 0, (c) 3, (d) 5.**

* Kinds: 31 load, 5 tests, 4 answers. Where both front ends loaded the file,
  15 files' test verdicts (422 tests) were compared, and 49 predicates'
  all-answers.
* No native gap (b) was found in this population.
* Native differs from both Scryer and Trealla only on `-0.0`. Both oracles
  read and print it as `0.0`, and the engine keeps it negative. That is 4 rows,
  across the three (c) files.

### Agreement on refusal (17, not differences)

Scryer refuses each of these too, except the two Scryer-only plumbing files
`tests/_scryer_toplevel.pl` and `tests/_scryer_end_module.pl`. Those use
Scryer internals and `term_expansion/2`, which both Clausal front ends refuse.

* The toklex spec files are data in a Prolog-like syntax (`then`).
* Nine doc blocks import an illustrative module that does not exist
  (`helpers`, `lib`, `kit`, `small_sizes`), or are fragments: `#=` with no
  clpz import, or a missing end token.
* The `reified_ite.md#L271` block redefines `,/2`.
* Three `translator_probe/tpkg` files import a sibling module by a dotted or
  slash path that does not resolve from the file.
* `s2/oracle/s2lib/shapes.pl` is the oracle stand-in.
* `s3pkg/__init__.pl` refuses only when it is loaded without its parent
  package on the path. With the path set, it is a (d) row above.

## Reading it

* Every load the translator refuses, the native front end accepts. No file
  regresses from loads to refused, except `dcg_grammar.pl`, and there native
  is the one that agrees with Scryer.
* For the 29 files that only native loads, the comparison stops at load.
  Their answers are checked against the oracle only by the slice exit tests,
  not by this harness.
* The gate pins all 40 rows. A new difference fails it, and so does a pinned
  row that disappears (prune the fixture). Rerun:
  `python -m clausal.tools.pl_parity --check tests/fixtures/pl_parity_known.json`
  (about 2 minutes with `-j 6`).
